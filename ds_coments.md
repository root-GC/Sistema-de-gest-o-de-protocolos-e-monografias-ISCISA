##TABELA DE COMENTÁRIOS###
Tabela comentários, assim facilita a gestão de comentários e feedbacks dos utilizadores do sistema. A tabela deve incluir campos como ID do comentário, ID do utilizador,  ID do trabalho/documento comentado, conteúdo do comentário, data de criação e status (ativo/inativo). Além disso, é importante implementar funcionalidades para filtrar, ordenar e pesquisar comentários.
